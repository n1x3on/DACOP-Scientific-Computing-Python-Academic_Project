# Course Summary

DACOP introduced scientific programming and computational problem solving using Python.

The course combined programming fundamentals with scientific computing and data analysis techniques commonly used in engineering, automation, and AI-related applications.

## Main Topics

- Python Programming
- Object-Oriented Programming
- NumPy
- Pandas
- Data Visualization
- Scientific Computing

## Practical Activities

- Programming Exercises
- Data Analysis Projects
- Scientific Computing Tasks
- Mini Software Projects
