# Treasure Hunt with NumPy

## Overview

This project implements a simple treasure hunt game using NumPy arrays.

A treasure is randomly placed inside a 5×5 map and the player navigates through the grid to locate it.

---

## Features

- Random treasure placement
- Grid navigation
- Move tracking
- Win detection
- Interactive gameplay

---

## Technologies

- Python
- NumPy

---

## Skills Demonstrated

- Array Manipulation
- Random Number Generation
- Algorithmic Thinking
- State Management

---

## Learning Outcome

This exercise demonstrates how NumPy arrays can be used for problem solving and game development.
