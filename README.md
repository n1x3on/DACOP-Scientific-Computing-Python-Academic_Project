DACOP: Scientific Computing and Data Analysis with Python
This repository contains coursework, programming exercises, and mini-projects completed during the DACOP module at Friedrich-Alexander-Universität Erlangen-Nürnberg (FAU) as part of my M.Sc. Artificial Intelligence studies.

The course focuses on scientific programming, object-oriented software development, numerical computing, and data analysis using Python.
