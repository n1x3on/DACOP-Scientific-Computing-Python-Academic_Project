# Object-Oriented Programming (OOP)

## Overview

This section contains coursework and programming projects focused on Object-Oriented Programming (OOP) in Python.

The exercises introduce fundamental OOP concepts and demonstrate how software can be structured using classes, objects, and reusable components.

---

## Contents

### Gym Chaos Simulator

A simulation project that applies object-oriented programming concepts to model interactions within a gym environment.

### Tic-Tac-Toe Project

A complete command-line Tic-Tac-Toe game developed using object-oriented programming principles.

Features include:

- Human vs Computer gameplay
- Input validation
- Winner detection
- Game state management
- Replay functionality
